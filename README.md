阿公和三叔停好摩托三轮后，也走了过来

“阿勋鱼中午现杀就行，先清洗一下生腌的材料，这个需要耗时间。”阿公提醒道。

“知道了，阿爸。”李勋应道。

“阿勋，我来吧，你去歇息一下。”阿嬷笑着拍了拍儿子的肩膀。 “嗯，也行，阿母你注意点，别被他们划着手。”李勋笑着起身。李哲宇看了一圈也没见到四叔和姑丈的人影，好奇的开口。 “爸，四叔和姑丈呢？”

“你四叔和四婶一早就去市区批发水果了，你姑丈去镇上的石材厂上班了。”李勋擦了擦手。

“批发水果，什么水果？”李哲宇一脸的疑惑。 “阿宇，他家包了一片果园，现在正是枇杷和杨桃成熟的时候，早上要去市区批发掉。”三婶说道。

“哦。”李哲宇点了点头，想了一下又开口。 “爸，我有个事想和你商量一下，你和我来一下。” “什么事？”李勋一脸疑惑的表情。 “来就知道了。”李哲宇喊着他上了二楼的客厅。父子俩坐在沙发上。

“哲宇有什么事吗？”李勋疑惑的看着儿子。 “爸，昨晚你们谈话，我也听到了。现在我们家也不缺钱了，适当的帮一下三叔、四叔，他们也能更好的在国内照顾阿公和阿嬷，你也不会被村里人说不顾兄弟。”李哲宇开口说道。

“我也想帮帮他们，毕竟是亲兄弟，但是一直没头绪，你有什么好的建议吗？”李勋看了一眼儿子。

“嗯，早上我忽然想起一件事挺适合三叔、四叔他们的。”李哲宇笑道。 “什么事？” “爸，你还记得我说过，一旦以后生活水平好了，城里的房子肯定会涨价吧。你说让三叔、四叔他们去拿地建房，怎么样？就和陈叔一样。“李哲宇说道。

“拿地建房？”李勋一脸的惊讶，疑惑着说道：“他们行吗，又没做过什么大生意，再说了，他们也不懂这一行啊！”

“不懂，可以先招几个懂行的人么，又不是要他们去做泥瓦工建房。做一次不就摸清里面的门道了。”李哲宇解释道。

“那本钱怎么办？这房地产行业可是不小的投资。”李勋想了一下，感觉也有道理。

“我想好了，现在国内没有限制这一块的外资占比，甚至还有鼓励外商来搞基建的意思。

我们可以注资占股份不就行了，再少的股份也比他们种地和打工强，你说呢？”李哲宇说道。2

“他们真能行吗？”李勋还是有点怀疑。 “对了，爸！你那个医生，我感觉也别做了，没什么意思。”李哲宇想了一下劝道。

“什么？怎么就没意思了，我就是学这个的，不做医生我做什么？”一听这话，李勋顿时急了。

“爸，上班不就是为了赚钱么，现在我们又不缺钱。你那一月几千美元的工作不如辞了，不如先帮我看一下DC资本。

而且，你也需要监督着国内三叔、四叔的这家房地产企业，他们可能不懂，不要而且，你也需要监冒着国内二救、四救的因为小事给搞砸了。”李哲宇和老爸说道。

“你这是真打算搞房地产吗？”李勋这也回味过来了，是这小子想搞一下，只是顺带加上了自己的几个叔父。

“嗯，可以试试，我很看好国内未来十多年的市场需求。但是，我没时间关注这些，错过就可惜了，就当是给你管理了。”李哲宇说道。

“我来管？”李勋顿时愣住了。

“嗯，我看我们这一大家子过年的时候人也不少，怎么还挑不出几个人才！”李哲宇打趣道。

“你是说，你大阿公、二阿公、三阿公家的都喊上？”李勋愣了一下。 “对啊，只要想外出打工的都可以，要是做的好，也可以分他们一点公司股份。毕竟是同族么，不然你们还出去单打独斗啊。”李哲宇说道。

“那我们要注资多少？他们可是掏不出什么钱来。”李勋点了一下头。 “一分钱不出可不行，那不是成了我们独资了么！”李哲宇连忙摇头，他后世在香港可是很了解大陆的房地产政策。

嘿，会不会说话呢，你阿母整天叨叨我就行了，你个患子回来才ー天也开始叨叨上了。”阿公听到儿子这话，瞬间不乐意了。
