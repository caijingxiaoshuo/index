Pantera Capital：算力资本市场的崛起

算力与数据中心基础设施支出已经形成万亿级赛道，规模堪比美国消费市场，成为美国经济增长的一大支柱。然而，随着 AI 智能体逐步渗透实体经济，算力需求持续高涨，但获取 GPU 的实际流程却依旧十分传统。市面上虽然已有 SF Compute、Vast AI、Runpod 等交易平台，但大量 GPU 节点的真实交易仍然依靠各类社群聊天渠道、场外（OTC）经纪商以及定制化双边协议完成。

当前，GPU 算力的金融化进程仍处于早期阶段。和电力一样，算力并非完全同质可互换的资产，它受到型号规格（SKU）、时间与地理位置三重约束。但展望 5-10 年后，算力很有可能演变为和电力、原油一样的大宗商品资产，成为支撑 AI 时代经济产出的全球性关键资源。本文将探讨这一演变过程：我们可以从电力市场借鉴哪些经验来理解算力市场结构、行业正在搭建的各类产品版图，以及算力商品化所蕴藏的机遇与尚未解决的问题。

一、借鉴电力市场
1.1 电力市场的架构
想要预判算力市场如何演化，我们不妨参考电力市场。与算力类似，电力具备异质性、时间属性、节点集中等特征，是全球经济增长的底层支撑。自 20 世纪 90 年代起，美国电力体系逐步推进私有化，发电、输电、配电一体化的垂直公用事业公司不断被拆分。独立电网运营商开始负责国内不同区域的调度；PJM West（东海岸）、ERCOT North（得州）、CAISO SP15（南加州）等大型电力枢纽，最终在洲际交易所（ICE）与芝加哥商品交易所（CME）形成可交易的商品合约，并成为该资产类别的一系列定价基准。

从物理层面看，电力市场本质上遵循“电网、运营商、节点”三层架构。顶层由多个物理上相互独立的区域电网构成。每个区域电网配有系统运营商 —— 区域输电组织（RTO）与独立系统运营商（ISO）。运营商管理众多本地变电站节点。以旧金山为例，城市供电由恩巴卡德罗、拉金、米申等多个变电站 “节点” 共同保障。每个节点的电价依靠节点边际电价（LMP）算法计算得出，该算法在发电调度、用户需求、输电物理成本、电力潮流物理规律等多重约束条件下开展优化求解。

节点边际电价（LMP）算法成为 1 瓦电力实物交割与 PJM-West 这类可交易电力基准品之间的关键纽带。电力的 “枢纽价” 与指数价格本质上是一篮子终端 LMP 节点价格的加权平均值。其中规模最大的一批基准最终具备了足够的稳定性与流动性，得以在芝加哥商品交易所（CME）、洲际交易所（ICE）等平台挂牌交易，并成为整个资产类别的参考定价。

1.2 关于算力市场的若干假说
回顾过去 30 年电力市场的演变历程，我们可以推导出几条关于算力市场的假说。

首先，算力市场或将沿用与电力市场相似的架构。在实物交割层面，电力市场 “电网 运营商 节点” 结构最贴切的类比是 “硬件 服务商 集群”。正如电力市场存在相互独立的实体电网，算力市场会以硬件芯片类型划分。H100、H200、B200、B300 等不同芯片品类，各自拥有独立（但互相关联）的定价基准。在 “运营商” 层级，存在多家算力服务商，例如 AWS、Nebius、Coreweave、SF Compute、Ornn。它们针对不同集群设置差异化定价，集群按时间、地理位置、硬件型号（SKU）区分，对应电力市场的节点。而和 LMP 最接近的对应机制，则是调度 / 路由算法：根据特定硬件规格的资源可用情况，输出动态实例价格。币安注册选哪个国家好呢? https://www.binance.com/zh-CN/square/post/15525897570657

电力市场中胜出、最终成为品类基准指数的标的（如 PJM-West、ERCOT-North、CAISO SP15），大多依托流动性最好的实物交割基础设施，这一点和原油等大宗商品市场的逻辑一致。算力领域未来会涌现大量基准指数，最终胜出的，大概率也是绑定高流动性实物交割场所的那一批。

此外，在电力市场中，尽管交易主体（发电方是空方、用电负荷方是多方）有时会直接在电力交易所做对冲，但大部分主体交易是通过银行与交易商旗下的场外交易柜台完成。场外柜台以一定价差将节点交割转换为枢纽交割，并对冲自身风险敞口。这套市场格局也可能在算力市场重现：算力的实际交易主体（新型云厂商与 AI 企业），可能更倾向于通过经纪商采购对应硬件规格资源，而非直接在交易所进行对冲操作。

最后，算力市场的基差风险可能显著高于电力市场。《联邦电力法》要求美国联邦能源监管委员会（FERC）强制公开电力批发行情，但算力市场并无这类强制透明化要求。这意味着算力动态价格（以及指数）只能依托自身订单簿，以及通过收益分成、数据采购协议合作的新型云厂商的订单簿来构建。

二、算力市场的架构
2.1 推理需求栈
电力市场的诞生源于电力的各类工业应用，同理，算力市场的底层驱动力来自 token 需求，尤其是推理 token 的需求。

当前，推理技术栈大致可划分为三个独立层级，共同构成算力市场的结构性多头与空头：

新型云厂商层（Neocloud layer）：Nebius、Coreweave 等主体运营实体数据中心，是 GPU 的卖方。

即时调用层（On-tap layer）：Fireworks、Baseten 这类开发者平台，将裸机环境封装成功能完备的 GPU 运行环境，开发者可直接在此运行任务、按需获取推理 Token。该层级属于 GPU 的买方。

应用层（Application layer）：Cursor、Perplexity、Rime 等应用依托上述推理平台，向个人用户与企业交付终端产品。该层级是推理 Token 的买方（而 Token 服务的底层消耗就是 GPU 算力）。

生态内各个参与者管理 GPU 的策略略有差异，但大体而言，新型云厂商是 GPU 市场的结构性空头，即时调用层与应用层则属于多头。而亚马逊、谷歌这类超大规模云厂商，会在整个技术栈的每一层都布局自研产品。关于 “利润流向”，有一个经验估算：上层应用每花费 100 美元购买 Token，约 45 美元流向即时调用层，50 美元流向新型云厂商 / GPU 资源层，剩余 5 美元归 OpenRouter 这类路由层。

2.2 算力资本市场架构
AI 交易主体这种底层结构性 “代币经济学”，决定了算力资本市场的形成形态。算力市场一种可能的演化路径为：多头方（开发者平台、应用层）与空头方（新型云厂商）两类 AI 交易主体，通过 SF Compute、Runpod、Compute Exchange 等算力经纪商与场外交易柜台完成特定硬件规格（SKU）的交易。而后算力经纪商与场外柜台进行库存管理，并承接终端 Token 消费者所需硬件规格与标准 H200 算力之间的基差风险；它们在 Architect、Pluto 等算力交易所开展对冲操作。交易所的定价，则依托合作的新型云厂商、场外平台订单簿加权计算形成的基准价格。

2.3 英伟达：算力领域的 “中央银行”
除此之外，英伟达近期宣布，计划将其 AI 工厂算力打造成为一类 “可投资资产”。在这套算力金融化体系中，凭借在 GPU 技术栈的垄断地位，英伟达可以被视作算力市场的 “中央银行”。中央银行通常具备三大核心目标：（1）调控经济体通胀；（2）实现充分就业；（3）充当最后贷款人。英伟达事实上正在扮演对应角色：

调控通胀：GPU 经济体中的 “通胀” 可以类比为芯片贬值周期，尤其是相对当前顶尖芯片（SOTA）的贬值速度。英伟达能够掌控新品发布节奏（例如 Vera Rubin 芯片），以此在一定程度上影响 GPU 长期贬值速率。

充分就业：英伟达追求 GPU 的 “充分就业”。若 Token 需求推高 GPU 利用率，市场就会产生更多 GPU 采购需求。因此英伟达有动力推动算力金融化，提升 GPU 小时的流动性，进而拉高硬件利用率。

充当最后贷款人：英伟达同时推出最高 25% 残值兜底政策。一旦新型云厂商及其他 GPU 服务商遭遇流动性危机，该政策可视作对 GPU 资产价值的救助与保险保障。

三、算力市场的机遇与挑战
3.1 算力技术栈对应的产品形态
随着算力市场金融化层持续扩张，行业有望诞生几大类核心产品，各自具备优势，同时也面临挑战。

产品一：实物交割。指将实体 GPU 资源交付至终端需求方，相关参与者包括 SF Compute、Hyperbolic、Vast、Runpod、Compute Exchange。这一层最贴近硬件底层，直接对接前文所述的各类 AI 交易主体。由于算力硬件规格品类繁杂，多数平台起步阶段仅充当经纪商，撮合算力需求方与各家新型云厂商并赚取佣金⁸。该赛道的终极目标是搭建算力 “现货交易所”。但在 GPU 实物交割环节持续稳定把控质量难度很高，对于算力供给来自去中心化网络的平台而言更是如此。这一层想要走向成熟，或许需要出现类似穆迪的评级机构，对底层交付资源的品质进行背书。

此外，尽管实物交割赛道竞争白热化，但长期来看它最容易构筑持久护城河。回顾原油、电力市场案例可以发现，指数、交易所、借贷等金融化业务，往往围绕流动性最好的实物交割场所生长。因此搭建成熟的实物交割体系具备极高价值。

产品二：指数产品。指搭建在算力资产之上的 “指数曲线”，Ornn、Silicon Data、Compute Desk、Semianalysis 等机构均在布局。构建指数是算力进一步金融化、实现可交易的关键一步。随着算力指数产品逐步成熟，“算力市场” 这一叙事迎来爆发；CME、ICE 等多家大型交易所也陆续宣布与算力指数机构开展合作。

然而时至今日，众多算力指数与各家独立 GPU 交易市场之间依旧存在巨大价差。造成价格分化主要有两点原因：第一，底层标的本身存在差异，不同平台在算力可靠性、可中断性以及合约条款上相去甚远；第二，各类算力指数依托的订单簿数据各不相同，并且算力行业不像电力等资产（受 FERC 监管），不存在强制信息透明的法规。当下不少算力指数只是向新型云厂商批量采购订单簿数据，或是通过合作、收益分成的方式搭建基础数据集。

除此之外，对比交易所和实物交割业务，指数层本身商业化难度更高。因此尽管指数能够制造声势，同时也是算力市场体系中不可或缺的一环，但单纯依靠指数业务，会同时承受来自底层实物市场（价格数据源）与上层交易所（要求收益分成）的双向挤压。

产品三：衍生品交易平台。技术栈第三层是交易平台（以现金结算期货为主），依托指数产品为算力提供对冲场所，Liquid Compute、Architect 等项目正在进行相关开发。长期来看，衍生品赛道最受关注、商业化潜力最强，但目前仍处于早期阶段，交易量尚不够可观。同时，现金结算平台的可交易标的是标准化 H200 算力实例，并非可以直接运行推理任务的特定硬件规格。因此在这类交易所开展交易的大多是场外交易柜台、算力经纪商，目的是对冲资产负债表上的算力库存风险，而非终端 AI 需求主体。

产品四：金融化载体。第四大类产品范畴更广，指服务算力融资的各类工具。例如借贷协议、资金库，以及 USD.AI 这类合成稳定币，为数据中心、新型云厂商的实体建设提供资金支持。未来市场还会出现风险转移与保险类产品，用来平滑 GPU 市场当中的基差风险。
